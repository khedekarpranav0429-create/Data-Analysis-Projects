# Data Analysis Case Study

## Overview

This project was completed as part of the **Meta Data Analyst Professional Certificate**.

The case study follows an end-to-end data analysis process, including data cleaning, data exploration, SQL analysis, visualization, and dashboard creation.

## Objective

The objective of this project was to analyze the provided business dataset, answer key business questions, identify meaningful patterns, and communicate insights through data visualizations and a Tableau dashboard.

## Tools Used

- Google Sheets
- SQL
- Tableau
- Data Cleaning
- Exploratory Data Analysis
- Data Visualization

## Project Process

### 1. Data Cleaning

Reviewed and prepared the dataset for analysis by identifying and addressing data quality issues such as missing values, duplicates, inconsistent data, and invalid values.

### 2. Data Exploration

Explored the dataset using Google Sheets to understand the data, calculate statistics, identify patterns, and answer the assigned business questions.

### 3. SQL Analysis

Used SQL queries to filter, group, aggregate, and analyze the data based on the requirements of the case study.

### 4. Data Visualization

Created charts and visualizations to communicate important findings and make patterns easier to understand.

### 5. Tableau Dashboard

Created an interactive Tableau dashboard to present the key findings from the analysis.
