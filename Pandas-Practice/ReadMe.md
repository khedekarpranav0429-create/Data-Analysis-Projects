# Pandas Practice

Practice notebooks to learn Pandas for data analysis.
I solve practice questions on a **synthetic orders dataset** (200 rows). The data is made up. It is not real customer data.

The questions are listed in [QUESTIONS.md](QUESTIONS.md). I will keep adding more.

## Skills practiced
- Loading data with `read_csv`
- Looking at data: `head()`, `tail()`, `columns`
- Selecting columns (Series and DataFrame)
- Selecting rows and columns with `loc` and `iloc`
- Boolean masks with `&`, `|`, `~`, `isin()`
- Finding missing and wrong values with `isna()` and `notna()`
